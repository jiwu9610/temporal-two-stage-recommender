## 3. 波次 3:序列模块(排序位)——干净测量的阴性结果

设计(外部评审全部采纳):残差式 `logit = DCN + α·g(cand, seq)`(α=0 逐位等于 DCN,消融纯净);
词表按 spec 刷新(refit 用 rt+ms 历史,OOV 归零);全部交互 + rating sparse id;
预注册 3 配置/类目(hstu / mh_pool+2层 / causal,均 delta 时间编码);DCN 双种子定噪声带。

**选型结果(model_selection,vs 同网格 DCN)**:
- Books:唯一超噪声带的 mh_pool(+0.4% R@100)R@10 −9.5% → guardrail 拒;
- Electronics:全部在带内或以下;
- VG:三变体 R@100 全部在 ±0.9% 噪声带内(平局),R@10 一致 +4~5%(注脚:该指标模式上次终测反转,不足以开终测)。

**按预注册规则:任何类目均不采纳,不进行第三次 test 读取。**
结论:在中位序列长度 1-2 的评论数据上,排序位 transformer 序列模块无法产生超出种子噪声的收益;
锚定实验(leg E:官方基准上 SASRec R@10=0.091 落文献带)证明这不是实现问题,是数据属性。
细分桶(5-9 / 10+ 历史)也未见可靠提升——长历史用户是全体系最弱桶,仍是开放问题。
